# Apex Renegade — Controller Mapping

The browser build uses the standard Web Gamepad API mapping and is intended to work with Xbox/XInput-style USB controllers and PlayStation controllers exposed by the browser as standard gamepads.

## Default mapping

- Left Stick — move
- Right Stick — look
- RT / R2 — fire
- LT / L2 — aim
- A / Cross — jump; ascend while flying
- B / Circle — crouch/slide; descend while flying
- X / Square — reload
- Y / Triangle — cycle weapon
- LB / L1 — dash
- RB / R1 — Apex Surge
- L3 — sprint
- D-pad Up — toggle flight once Refusal III is unlocked
- D-pad Left / Right — cycle weapon

Controller input can start the game directly from the title screen without requiring pointer lock. Mouse/keyboard input remains available at the same time.

Supported pads with vibration actuators receive light recoil, damage, Apex Surge, and Refusal-breakthrough rumble feedback.
